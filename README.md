# Sistema de Gestión de Imágenes en Go

Proyecto desarrollado en Go como parte del Proyecto Integrador de Tercer Semestre - Ingeniería en Sistemas de Información - UIDE.

## Tecnologías utilizadas

- **Go** - Lenguaje principal del sistema
- **Gorilla/Mux** - Enrutamiento HTTP
- **SQLite** - Base de datos
- **net/http** - Servidor web nativo de Go
